# actuarial-portfolio-project# Projet Actuariat — Pricing, Underwriting Risk & Portfolio Monitoring

Projet personnel appliquant les techniques actuarielles de base (pricing GLM,
souscription, suivi de portefeuille) sur le dataset French Motor Third-Party
Liability (freMTPL2freq/sev).

## Structure
- `notebooks/` : analyse exploratoire et modélisation, étape par étape
- `src/` : fonctions réutilisables (chargement des données, moteur de pricing)
- `dashboard/` : app Streamlit de suivi de portefeuille (à venir)
